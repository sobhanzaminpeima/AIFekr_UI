# Live module migration batch — 2026-10-31

Six more registered modules now have API adapters: lead generation (7 views), business doctor (5), meetings (2), website designer (4), referrals (5) and startup builder (6). The existing design components and backend authorization, prices and credit costs remain authoritative. German/Turkish labels use the existing English fallback.

Lead generation includes form CRUD, fixed field visibility/requirements, public links and the real JavaScript embed loader, submissions, channel reporting, Meta requests/OAuth and Google connector controls. Connector credentials are shown only after an explicit reveal, never logged. Creating/rotating Google keys and disconnecting connectors require confirmation.

Business doctor exposes stored assessment history. Meetings expose only the account's saved meeting conversations. Streamed tools show progress, require the backend completion marker, reject blank results and label interrupted output as incomplete; there is no automatic paid retry. Website preview runs in an isolated iframe, and the HTML endpoint now also sends sandbox CSP even when opened directly. A local HTTP test found the generic Next headers overriding the route CSP; the specific header rule corrects that.

Referral views use the real shared referral code, a server-generated QR, actual invite/purchase/commission records and existing payout requests. Payout amounts are explicitly entered/displayed in the backend's canonical Toman unit; no rates or fees were changed. Request submission reserves funds through the existing API and is not represented as a completed bank payout. Startup projects support all four existing generation stages; a generated result is reviewed and saved explicitly, allowing a save retry without another paid generation.
